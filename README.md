# HOG CRANKERS

**NOBODY CRANKS ALONE.**

An open-world action-comedy riding game. You are HOSS, stranded in CRANK COUNTY.
The only stat is PACK RESPECT, earned through acts of brotherhood. Your hog can
be anything. The H.O.A. hates joy. The moon is a flaming skull, because it should be.

▶ **PLAY: https://optimizedwf.github.io/hog-crankers/**

## How to ride

| Key | What |
| --- | --- |
| W / ↑ | Throttle |
| S / ↓ | Brake |
| A / D | Steer |
| SPACE (hold, then release) | CRANK HOG — release in the sweet spot for MAXIMUM CRANK |
| C | Camera |
| M | Mute |
| P | Pause |

Answer the BROTHERS IN NEED. Tow them. Earn PACK RESPECT.
Hold SPACE too long and you'll OVERCRANK — the engine blows and the Pack has to
tow *you*. That's not shame, that's brotherhood.

## Difficulty

- **CASUAL CRANKER** — wide window, gentle climb
- **CERTIFIED HOSS** — the intended crank
- **ABSOLUTE MFER** — brutal window, one heartbeat before OVERCRANK
